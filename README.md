🚀 DevOps CI/CD Pipeline for Node.js Application (Docker + Azure)

📌 Project Overview

This project demonstrates a complete end-to-end DevOps CI/CD pipeline for a simple Node.js web application. The application is containerized using Docker and deployed on an Azure Virtual Machine using automated pipelines built with Azure DevOps.

The goal of this project is to simulate a real-world production deployment workflow where every code change pushed to the repository is automatically built, containerized, and deployed to the cloud.

⚙️ Tech Stack

Node.js (Express.js)

Docker

Azure Virtual Machines (Ubuntu)

Azure DevOps Repositories

Azure DevOps CI/CD Pipelines (YAML)

Git


🔁 CI/CD Workflow

Developer pushes code to Azure Repos (Git)

Azure DevOps Pipeline is triggered automatically

Application is built and Docker image is created

Docker image is deployed to Azure VM

Updated application is available live on server

🐳 Key Features

Simple Node.js web server

Dockerized application for portability

Automated build and deployment pipeline

Cloud deployment on Azure VM

Fully automated CI/CD workflow using YAML pipelines

Zero manual deployment after setup

🎯 Project Goals

Learn real-world DevOps practices

Understand containerization using Docker

Implement CI/CD pipelines using Azure DevOps

Deploy applications on cloud infrastructure (Azure VM)

Automate end-to-end software delivery lifecycle

🌐 Outcome

After setup, any code change pushed to the repository will automatically:

👉 Build the application

👉 Create a Docker image

👉 Deploy it to Azure VM

👉 Reflect changes live on the website
